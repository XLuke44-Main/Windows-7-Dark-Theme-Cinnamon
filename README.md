# Windows 7 Dark Theme — Blue Edition

Dark-themed fork of https://github.com/Xalalau/Windows-7-theme-cinnamon

**Blue Edition** stays closer to the original theme's look and feel, with blue accents and a dark appearance.

There are two editions of this theme:

- **Windows-7-dark-theme-blue** — The edition closest to the original, featuring blue accents.
- **Windows-7-dark-theme-green** — A variation featuring lively green accents.

Both editions are made for the **Cinnamon desktop environment**.
